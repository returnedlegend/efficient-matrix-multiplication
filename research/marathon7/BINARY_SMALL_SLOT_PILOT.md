Bounded six-slot pilot
======================

This new operator holds eight of the fourteen approximate compact products
fixed and exactly replaces the other six. Its residual target includes every
coefficient of the unchanged original fifteen-product packet. The approximation
starts from the same pinned minimum-volume drop-one state as the unsuccessful
factor-block baseline, rather than from a different target tensor.

This changes the available move. A factor-block step fixes two entire factor
blocks and optimizes the third; a six-slot repair changes all three factors of
six products jointly. It also permits arbitrary binary factor points in the
residual mode images. It is therefore not confined to the old finite atom
dictionary whose isolated odd-cycle extensions were certified dominated. The
known n2 control demonstrates an escape, but gives no assurance of N5 success.

For each of nine d11 packets, enumerate at most600 of the3003 six-subsets of
fourteen slots. The selection is fixed before solving: seed7160600 plus case
ordinal, stratify by the smallest selected slot0..8, allocate one choice to
each stratum then proportional remaining quotas using largest remainders,
shuffle each stratum with the recorded Python RNG seed, and interleave strata.
All selected literal subsets and their digest are included in the selection
manifest and independent QA binding. There are no adaptive additions.

A mode rank above six is a complete exclusion for that fixed complement only.
Other residuals are compacted with a checked full inverse. Supported CP(d),
CP(d+1), CP(d+2) decisions use the existing reviewed decoders. Completed exact
CP6 negatives may be reused only for identical binary compact coefficients,
shape and target six. The first result, input and code pins form the proof
object, and each reuse records its hash. Unknown results are never cached as
negatives. Rank exclusions, exact exclusions, calls, cache hits and unknowns
are reported separately. The best original full-target state is retained.

The overall result of any unsuccessful sampled family is UNKNOWN, including
when all600 subsets were individually excluded. No CP14 case is closed by this
heuristic. A raw compact positive is separately checked by packed and scalar
full-target expansion, then enters the unchanged reviewed run_case lifecycle:
lift through the pinned original mode bases, replace the fifteen literal source
products, persist hidden raw bytes, independently verify all15625 coefficients
twice, and publish only through fresh guarded barriers. C7 owns global freeze.
The driver creates no local winner marker. Late/error paths use the existing
quarantine protocol and retain raw evidence without claiming a timely result.

The authorized envelope is one run, nine cases, at most12 seconds each,
120-second total guard,150-second outer timeout, CPU1 nice10,1024MiB address
space,32MiB output and the immutable C7 absolute cutoff. Independent source/core
QA already binds the same nine original cores; separate operator/runtime QA
must bind the new code closure and subset digest before launch.
